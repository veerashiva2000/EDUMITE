#### 🛡️ **Row Level Security (RLS)**
```sql
-- Users can only access their own data
CREATE POLICY "Users view own profile" ON users
  FOR SELECT USING (auth.uid() = id);

-- Courses: Public read, authenticated write
CREATE POLICY "Courses public read" ON courses
  FOR SELECT USING (true);

CREATE POLICY "Courses auth insert" ON courses
  FOR INSERT WITH CHECK (auth.uid() IS NOT NULL);
```

## 🤟 **Sign Language System - Technical Deep Dive**

### **🎭 CWASA Library Integration**

EDUMITE uses the **Communication With Avatars - Signing Avatars (CWASA)** library developed by the University of East Anglia. This is a 183,000+ line JavaScript library that renders 3D humanoid avatars performing sign language gestures.

#### **Technical Architecture**

```javascript
// CWASA Configuration
const config = {
  avsbsl: ["anna"],           // Avatar model (anna, marc, luna, francoise)
  sysPath: "/jas/loc2021",    // SiGML interpreter path
  autoLoad: true,             // Auto-initialize on container detection
  cwa_frameWidth: 500,        // Render width
  cwa_frameHeight: 500,       // Render height
  cwa_defaultScale: 1.0       // Avatar scale
};

// Initialization Flow
1. HTML container: <div class="CWASAAvatar av0"></div>
2. CWASA auto-detects .CWASAAvatar class
3. Loads SiGML interpreter from sysPath
4. Initializes WebGL renderer
5. Loads avatar model (Anna = ~2MB 3D mesh)
6. Ready to play SiGML files
```

#### **SiGML (Sign Language Markup Language)**

```xml
<!-- Example: "HELLO" in ISL -->
<?xml version="1.0" encoding="utf-8"?>
<sigml>
  <hamgestural_sign gloss="HELLO">
    <sign_manual>
      <handconfig handshape="flat" thumbpos="out"/>
      <handconfig certi="TT" extfidir="dl"/>
      <location_hand contact="touch" location="forehead"/>
      <rpt_motion repetition="fromstart">
        <directedmotion direction="d"/>
        <directedmotion direction="u"/>
      </rpt_motion>
    </sign_manual>
    <sign_nonmanual>
      <mouth_gesture movement="C07"/>
      <eye_brows movement="RB"/>
    </sign_nonmanual>
  </hamgestural_sign>
</sigml>
```

### **🔤 ISL Translator**

**File**: `src/pages/SignLanguageTranslator.tsx`

**Algorithm**:
```javascript
1. User inputs text: "Hello how are you"
2. Tokenize: ["Hello", "how", "are", "you"]
3. Lowercase + normalize: ["hello", "how", "are", "you"]
4. Lookup in ISL_DATASET:
   - "hello" → "hello.sigml" ✅
   - "how" → "how.sigml" ✅
   - "are" → "are.sigml" ✅
   - "you" → "you.sigml" ✅
5. Generate SiGML file list
6. Pass to CWASAAvatar for playback
```

**Missing Sign Handling**:
- If word not in dataset → Fingerspell each letter
- Example: "EDUMITE" → ["e.sigml", "d.sigml", "u.sigml", "m.sigml", "i.sigml", "t.sigml", "e.sigml"]

## 🔒 **Security**

### **Supabase Row Level Security (RLS)**

All database tables are protected with RLS policies:

```sql
-- Users can only access their own data
CREATE POLICY "Users view own profile" ON users
  FOR SELECT USING (auth.uid() = id);

-- Courses are public read, authenticated write
CREATE POLICY "Courses public read" ON courses
  FOR SELECT USING (true);

CREATE POLICY "Courses authenticated insert" ON courses
  FOR INSERT WITH CHECK (auth.uid() IS NOT NULL);
```

### **Authentication Flow**

1. User registers/logs in via Supabase Auth
2. JWT token stored in localStorage
3. Token automatically sent with API requests
4. RLS policies validate user identity at database level

### **Best Practices**

- ✅ Never commit `.env` file (already in `.gitignore`)
- ✅ Use environment variables for all secrets
- ✅ RLS policies protect all user data
- ✅ CORS configured for Express proxy
- ✅ Input validation with Zod schemas

#### **1. CWASA Avatar Not Loading**

**Symptoms**: Stuck on "Loading avatar..." indefinitely

**Solutions**:
```typescript
// ✅ Check 1: Container ref exists
useEffect(() => {
  if (!containerRef.current) {
    console.error('Container ref is null!');
    return;
  }
  // Initialize avatar...
}, []);

// ✅ Check 2: Overlay pattern (not conditional return)
return (
  <div className="relative w-full h-full">
    <div ref={containerRef} className="CWASAAvatar av0 w-full h-[500px]" />
    {isLoading && (
      <div className="absolute inset-0 flex items-center justify-center bg-obsidian/90">
        <Loader2 className="animate-spin" />
      </div>
    )}
  </div>
);

// ✅ Check 3: Verify SiGML files exist
console.log('SiGML files:', sigmlFiles.map(f => `/SignFiles/${f}`));
```

```typescript
// ✅ Implement exponential backoff
const retryWithBackoff = async (fn: () => Promise<any>, retries = 3) => {
  for (let i = 0; i < retries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === retries - 1) throw error;
      await new Promise(r => setTimeout(r, Math.pow(2, i) * 1000));
    }
  }
};

// ✅ Cache responses
const cache = new Map();
const getCachedResponse = async (prompt: string) => {

  const response = await gemini.generate(prompt);
  cache.set(prompt, response);
  return response;
};
```
